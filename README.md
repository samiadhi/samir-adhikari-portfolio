# Samir Adhikari — STAR Portfolio Website

A responsive, static portfolio site prepared for the TCOM291 STAR Portfolio assignment. The site uses HTML, CSS, and vanilla JavaScript and is structured for GitHub Pages.

## Files

- `index.html` — main portfolio page: About, Skills & Certification, three project STAR narratives, résumé link, and Contact.
- `resume.html` — public résumé page with a Print / Save as PDF button. It omits a phone number and home address.
- `styles.css` — responsive styling, mobile navigation, project previews, and print/page layout support.
- `script.js` — mobile navigation, project filters, and subtle scroll-reveal behavior.
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing for this simple static site.

5. Review the public résumé for accuracy and use **Print / Save as PDF** on `resume.html` if you want a PDF copy. Since it is public, keep personal information limited to what you want employers to see.
6. Open the site locally and test it at phone and desktop sizes.

## Publish with GitHub Pages

1. Create a GitHub repository for the portfolio. If using GitHub Free, make the repository public for Pages hosting.
2. Upload the contents of this folder to the repository root, including `index.html`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)` folder and save.
5. After Pages finishes publishing, use the **Visit site** link from the Pages settings and test the published site in a private/incognito window.

Official guide: https://docs.github.com/en/pages/quickstart
